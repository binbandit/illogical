# Visual and interaction reference

Selected evidence for reproducing the macOS client. The complete collection is in [frames](frames), indexed by [sources.json](sources.json). These are compressed video samples, sometimes rescaled; they establish composition and behavior, not exact font metrics or colors in macOS points. The desktop wallpaper and presenter's camera overlay are not application UI.

## 1. Latest demonstrated split surface treatment

**V13, 0:18, 8 September.** Horizontal tabs share a compact titlebar with the traffic lights, session control, and trailing add button. Terminal blocks have a small header with title and controls, rather than a heavy toolbar. Comfortable density separates blocks with narrow gutters and rounded outlines. One tall right pane sits beside two stacked left panes.

[Comfortable density with three terminal blocks](https://x.com/almonk/status/2097439320076403125)

**V13, 0:25.** Compact density removes the separated islands in favor of adjacent panes and fine separators. The open style menu establishes the labels Modern, System, Themed, and Blended. Selection highlight and checkmark are distinct states: the highlighted row need not be the currently applied style.

[Compact density and interface style menu](https://x.com/almonk/status/2097439320076403125)

Implementation detail to preserve: density changes the terminal container geometry and decoration. It is not merely a font-size setting.

## 2. Vertical navigation

**V08, 0:07, 27 August.** A light sidebar uses session headings, process icons, truncated terminal titles, and a rounded active row. A filter and two action icons sit at the bottom; an add control sits above the list. The terminal remains a large quiet surface to the right.

[Vertical session and terminal list](https://x.com/almonk/status/2092908172381982782)

The accompanying post explicitly says vertical navigation spans sessions and machines. Horizontal navigation stays scoped to one session. Treat that information architecture as part of parity, not just an orientation preference.

## 5. Session overview

**V04, 2:55.** Continuing the downward gesture produces groups of live previews under session labels. Each preview retains its process icon and title. Clicking chooses a destination. This is an application-local overview, despite the comparison to macOS Mission Control.

[Session overview with grouped live previews](https://x.com/almonk/status/2087533118429294920)

## Visual acceptance procedure

For each implemented state, recreate the same number and arrangement of blocks, comparable terminal content, appearance, and window proportions. Compare screenshots at a controlled backing scale. Check active/inactive tabs, focus, text truncation, split borders, material tint, terminal insets, and clipping before adjusting small dimensions.

Keep measurements tagged as inferred until a source provides actual values. Never derive a macOS point measurement directly from a rescaled video pixel. For gestures, search, and persistence, compare the sequence and state changes in addition to the final still frame.
