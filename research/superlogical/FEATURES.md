# Feature inventory

Research baseline: 20 September 2026. Source IDs refer to [SOURCES.md](SOURCES.md). Timestamps are offsets into the original video, not the displayed social-media date.

## Terminal and persistence

| ID | Target behavior | Evidence | Remaining uncertainty |
|---|---|---|---|
| T01 | Launch directly into a usable native terminal, with minimal startup delay. | Observed/stated: V09, 0:00-0:43. | No reproducible startup benchmark or supported hardware matrix. |
| T02 | Run ordinary shells and full-screen terminal applications, including the demonstrated editors and monitors. | Observed: V09, 0:43 onward; V14. | Full terminal conformance and all graphics edge cases were not tested. |
| T03 | Closing/quitting the GUI leaves processes running; reopening reconnects to their current state. | Observed: V09, 0:57-1:37; the counter advances while the app is closed. | This proves GUI detachment, not survival of an OS reboot or process crash. |
| T04 | Restore the last selected session when reopening. | Observed/stated: V09, 1:39 onward; V12, 3:59. | Which navigation preferences are per window, client, or server is not fully disclosed. |
| T05 | Scroll and select terminal text using the native client; each client has its own viewport. | Observed: V09, 2:01. Stated: V02, 5:00 onward; [developer clarification](https://x.com/mitchellh/status/2093830565925671415) says scrollback and search are client-local and mobile already reflows locally without resizing the server. | Exact selection rules and accessibility behavior. T08 covers optional synchronization; the mobile reflow statement does not establish the same macOS resizing UI. |
| T06 | Attach quickly to the active screen while older scrollback loads asynchronously. | Stated: V02, 1:57-3:21 and 5:00-5:59. Upstream: G03. | Actual transport framing, limits, compression, and flow control. |
| T07 | Keep idle terminal state inexpensive by parking emulator state and reducing idle PTY polling resources. | Stated: V11, 3:55-11:21. | Threshold configurability, encryption details, crash guarantees, and measured resource costs. |
| T08 | Optionally synchronize client viewports for shared work, while retaining independent viewports by default. | Stated: [developer reply](https://x.com/mitchellh/status/2082951625879265505) in the V02 discussion of co-debugging. | Exact opt-in controls, selection ownership, conflict handling, and follow/unfollow behavior are not disclosed. |

“Persistence” must be specified by failure boundary. GUI quit, disconnected network, server restart, and machine reboot are different cases. The strongest directly observed guarantee here is processes surviving the GUI client quitting.

## CLI and terminal-block interface

V14 demonstrates session creation, process launch, splits, moving a running editor, tab naming, metadata inspection, event watching, process inspection, and session destruction. `--keep-open` retains a block after its child exits; `wait` can block until that exit. V15's 2048 game illustrates programmable layout changes, not a separate built-in product feature.

Commands visible in the CLI help at **V14 7:17**:

| Area | Commands |
|---|---|
| Everyday operation | `new`, `attach`, `ls` / `list`, `run`, `split`, `send`, `send-key`, `capture`, `kill` |
| Layout | `focus`, `zoom`, `move`, `swap`, `resize` |
| Resources | `session`, `window`, `block`, `client` |
| Automation | `events`, `wait`, `api` |
| Server/login | `server`, `login-server`, `whoami` |

Nine methods are visible in the terminal block inspector at **V14 4:01**:

| Method | Observable or advertised purpose |
|---|---|
| `format` | Capture terminal contents in formats including text, HTML, and VT. |
| `list_dir` | List subdirectories as the terminal's child would resolve the requested path. |
| `process` | Return child/foreground process information and last-exit information. |
| `reset` | Reset terminal emulator state while preserving block/process identity. |
| `resize` | Request terminal size or release size ownership. |
| `set_theme` | Change terminal theme. |
| `size` | Inspect grid/cell dimensions, owner, and requested sizes. |
| `title` | Return the current terminal title. |
| `write` | Send bytes to the PTY as user input. |

Ten advertised events: `bell`, `child_exited`, `clipboard_written`, `desktop_notification`, `progress_report`, `pwd_changed`, `selection_copied`, `size_changed`, `title_changed`, and `url_clicked`.

Metadata includes block and session IDs, label, creator/flavor identifiers, host, placement, window, supported methods, and events. Process output shows child and foreground process identity, executable, user, working directory, home directory, and last exit status. The frame preserves exact spellings in [the visual reference](VISUAL_REFERENCE.md).

The CLI also lists connected clients, including short-lived CLI connections. This suggests a shared control plane, but the public material does not publish an RPC schema, event ordering guarantee, or compatibility promise. Treat resource names as evidence, not permission to invent undocumented flags.

## Broader scope and gaps

The [official site](https://www.superlogical.com/) describes local/remote durable work, native and web access, live sharing, and a longer-term progression into composable tools and operations. A [developer reply](https://x.com/mitchellh/status/2083192111105724652) confirms a working browser prototype; P04 says an internal iOS app is in use. The [mobile reflow answer](https://x.com/mitchellh/status/2093830565925671415) describes local resizing for normal shell operations without server resize. No full web/iOS walkthrough was reviewed, and these statements do not establish a shipped cross-platform feature matrix.

Keep future work separate from existing capabilities: [Kubernetes integration](https://x.com/mitchellh/status/2093462095790793104) and a [floating panel](https://x.com/mitchellh/status/2093538201675940173) are affirmative plans. A [notification inbox](https://x.com/mitchellh/status/2093533044162625749) is active design exploration. Per-workspace themes, capability negotiation, and the proposed resize/resync controls also remain intentions rather than verified current contracts. The paired questions and answers are preserved in the three reply research notes linked from [SOURCES.md](SOURCES.md).

Not established: release date, pricing, final public name, complete settings format, wire compatibility, collaborative permissions UI, server-reboot process recovery, offline command queues, detailed reconnect semantics, exact font assets, accessibility conformance, or full theme values. These remain explicit gaps, not implied features of illogical.
