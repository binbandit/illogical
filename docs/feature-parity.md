# Feature parity audit

Full parity is not verified; known missing/partial behavior remains.

Audit date: 20 September 2026. This document compares the current native macOS implementation with the observed and stated behaviors in the [research inventory](../research/superlogical/FEATURES.md). It consolidates the [navigation](audit-navigation.md), [service and CLI](audit-service.md), [remote and input](audit-remote-input.md), and [rendering, appearance, and search](audit-rendering.md) audits. The initial audit was followed by an implementation pass addressing reproduced defects and demonstrated missing workflows; updated rows distinguish verified behavior from remaining acceptance limits.

The implemented core includes persistent processes across client disconnection, coherent terminal snapshots, native sessions and nested splits, working control keys, representative Nerd Font rendering, and sustained output with bounded queues. That does not establish support for every demonstrated feature, a 1:1 UI, complete Ghostty compatibility, or consistent half-bounce startup.

## Status and evidence boundaries

- **Verified, bounded**: the stated acceptance case passed, or the specifically identified implementation behavior was directly checked. The adjacent limits remain part of the result.
- **Partial**: an implemented subset exists, with a known defect, missing behavior, or substantial outstanding acceptance work.
- **Missing**: the defining behavior has no implementation.
- **Unverified**: a plausible implementation exists, but the required acceptance scenario has not been demonstrated.

The 43 rows below cover every current research feature ID. The separate [C01-C47 service matrix](audit-service.md#cli-commands-visible-in-v14) covers every listed CLI command, all nine advertised block methods, all ten advertised events, and the remaining resource/lifecycle behavior. Those IDs are audit-local and are not claims about an unpublished Superlogical API. A method name, setting label, or passing transport test alone does not establish working end-to-end parity.

## Implementation follow-up

The reproduced dense/wrapped search, stale counter, reconnect-query and low-contrast failures have maintained regressions and fixes. Service corrections cover relative directory lookup, implicit run context, attached theme delivery, richer inspectors, native focus requests, lifecycle commands and input automation. Native work adds per-pane search, copy feedback and copy-on-selection, Reduce Motion handling, broader focus/mouse input and process-aware icon selection. Resource changes and measured limits are recorded in [resource-efficiency.md](resource-efficiency.md).

Short-outage replay uses a bounded mutation history, explicit resync when unavailable, and complete-history/sequence validation in the native client. Opt-in viewport synchronization leaves default scrolling independent. Neither feature changes the underlying process or uses terminal resize to implement scrolling.

Remaining claims need evidence rather than labels: exact private theme palettes and UI metrics, physical three-finger gestures, full graphics/contextual shaping, a matched Ghostty baseline, external Linux/tailnet deployment and broader multi-user sharing. The original reproductions remain in the area audits as historical evidence; current outcomes are recorded in their implementation addenda and the rows below.

## CLI and block interface coverage

Use the full [C01-C47 service matrix](audit-service.md#cli-commands-visible-in-v14), including its [method](audit-service.md#the-nine-advertised-terminal-methods), [event](audit-service.md#the-ten-advertised-events) and [resource/lifecycle](audit-service.md#other-demonstrated-cliresource-semantics) sections. It compares the actual command and method behavior with V14's visible [CLI help at 7:17](https://x.com/mitchellh/status/2099622049325232505), [block inspector at 4:01](https://x.com/mitchellh/status/2099622049325232505) and [process inspection at 6:15](https://x.com/mitchellh/status/2099622049325232505).

The [current implementation addendum](audit-service.md#implementation-follow-up-20-september-2026-service-parity-package) supersedes the historical failures. CLI attach/focus selects one native viewer; client/server command families and session/window inspectors return actual resources. Run inherits its invoking terminal context, relative directory lookup uses terminal cwd, and block/window/session waits preserve child exit status. Theme defaults propagate to attached clients. Desired resize requests survive owner turnover; lazy process inspection reports child and foreground group leader. Protocol-aware key/mouse automation and JSON method payloads have real-child acceptance tests.

All ten named event paths exist. Clipboard writes reach watchers and attached clients once; native selection-copy and OSC 8 Command-click produce their corresponding events. The combined native pass double-clicked a word and observed its exact text in the service event stream. The native URL test uses an injected opener rather than launching a browser. Events are not durably replayed, clipboard success does not acknowledge an OS clipboard write, and event filtering is not an authorization boundary.

Important limits remain: attach does not launch the GUI or provide a legacy terminal frontend; resource waits cover children present when the wait starts; foreground process metadata is not a complete pipeline tree; same-UID PAM is not a multi-account login broker. Method names, inspectors and passing tests do not establish undocumented Rex schemas, flags or exact arbitration behavior.

This is an audit against the identified public evidence, not proof that every public reply or unpublished feature has been found. Fresh source discoveries must add inventory rows and acceptance cases before any completeness claim is upgraded.

The [official site](https://www.superlogical.com/) also describes native/web access, durable local/remote work, live sharing and a longer-term direction toward composable tools and operations.
